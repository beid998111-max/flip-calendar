# 撕历 · Tear-off Calendar

> 每日一撕，每日一思。把纸质翻页日历背面的手写反思，搬到线上并系统化。

🔗 **在线访问：https://beid998111-max.github.io/flip-calendar/**

## 缘起

灵感来自豆瓣每年的电影日历——撕下当天那页，翻到背面写下今日的收获与心得。
纸质版的痛点是**信息无法系统整理**：写过的内容散落在一叠纸里，无法检索、无法关联、无法复盘。
这个项目保留了撕页的仪式感，同时补上纸质日历做不到的那部分。

## 功能

| 模块 | 说明 |
|---|---|
| 📅 **日历** | 正面为每日电影海报（每天不同色调 + 电影台词），点击卡片 3D 翻页至背面 |
| ✍️ **书写** | 键盘输入（今日收获 / 做对了什么 / 待改进）+ 手写板模式，支持标签 |
| ✂ **撕页** | 保存时触发撕页动画，记录存入知识库 |
| ✨ **星图** | 每天一颗星，共享标签的日子连成星座；悬停预览、点击跳回当天 |
| 📊 **复盘** | 月度统计、打卡热力条、做对/待改进汇总、标签分布、自动生成洞察 |
| 💾 **数据** | localStorage 本地存储，支持导出 / 导入 JSON |

## 使用

在线直接打开即可，无需安装。也可克隆到本地：

```bash
git clone https://github.com/beid998111-max/flip-calendar.git
cd flip-calendar
# 直接双击 index.html，或起个本地服务
python3 -m http.server 8080
```

## 跨设备同步（GitHub Gist）

点击右上角「云同步」，用你自己的 GitHub 私密 Gist 作为数据库，两台电脑自动同步。

**第一台电脑**
1. [创建一个 token](https://github.com/settings/tokens/new?scopes=gist&description=撕历云同步)，**只勾选 `gist` 权限**，有效期选 No expiration
2. 粘贴 token，Gist ID 留空 → 自动创建云端仓库
3. 记下面板里显示的 Gist ID

**第二台电脑**：填入**同一个 token** + 上一步的 **Gist ID**，数据自动接上。

**同步机制**
- 保存记录后 1.5 秒自动上传；打开页面自动拉取
- 冲突处理：逐条比对时间戳，**新的覆盖旧的，两边独有的都保留**，不会丢数据
- 手写图按月分片存储并降采样至 620px，规避 Gist 单文件 1MB 限制

**成本**：全部免费。GitHub Pages 免费额度为 1GB 存储 / 100GB 月流量，Gist 私密不限量，一年纯文本记录约 144KB。

**安全**：token 仅存于本机浏览器 localStorage，不经过任何第三方服务器。因只授予 `gist` 权限，即便泄露也无法操作你的代码仓库。
